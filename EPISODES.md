# Episode pipeline (OpenCrab pack -> long-form video)

## Folder tree
```
episodes/<ID>/episode.json      # source of truth: scenes, shots, narration lines, captions, clip trims, image motion
episodes/<ID>/notes/            # edit notes, sources
public/episodes/<ID>/keyframes/ # S01-01.jpg ... (GPT keyframes, 1920px)
public/episodes/<ID>/clips/     # S01-02.mp4 ... (Veo highlight clips)
public/episodes/<ID>/audio/narration/  # <SceneLine>.wav (generated by scripts/tts.mjs)
src/episodes/<ID>.manifest.json # generated timings (scripts/build-manifest.mjs) - do not edit by hand
src/episodes/registry.ts        # add new episode manifests here
src/compositions/EpisodeVideo.tsx, src/components/*  # shared renderer for every episode
out/<ID>/                       # renders
```

## Commands (run in Terminal from this folder)
```bash
# 1) narration (macOS say, voice set in episode.json) + timings
npm run prep --ep=BIB-GEN-001

# 2) preview in the browser editor
npm run dev

# 3) render (half-res preview, then full HD)
npm run render:preview --ep=BIB-GEN-001
npm run render:final --ep=BIB-GEN-001
```

Notes
- If a narration WAV is missing, build-manifest estimates its length from word count and the line is rendered silent (manifest field `audioEstimated: true`).
- Clip trims (`segments`) in episode.json are in seconds of the source clip; e.g. S03-01 uses [[0,3],[5,8]].
- Image `motion`: zoomIn | zoomOut | panLeft | panRight | driftUp | static.

## Background music (bgm)
- `episode.json > bgm.cues[]`: `src` (under public/episodes/<ID>/), `startScene` + `startOffsetSec`, `endScene` + `endOffsetSec` (omit = until the end), `trimStartSec` (seconds skipped in the file), `fadeInSec`, `fadeOutSec`, `gain`.
- Cues are anchored to scenes, so they follow narration timing changes after `build-manifest`.
- `volume` = level with no narration, `duckVolume` = level under narration (`duckAttackSec`/`duckReleaseSec` ramps).
- BIB-GEN-001 music: Google Flow Music (Lyria 3.5) on Google AI Pro (Flow Music Plus plan lists commercial use rights). All takes kept in `audio/bgm/takes/`.

## Series thumbnail (fixed format)
- Spec: `episodes/<ID>/thumbnail.json` (series, ep number, source, title lines, optional highlight circle), background image in `public/episodes/<ID>/`.
- `node scripts/build-manifest.mjs <ID>` copies the spec into `src/episodes/<ID>.thumbnail.json`; add the episode to `THUMBS` in `src/episodes/registry.ts`.
- Render: `npm run thumb --ep=<ID>` -> `out/<ID>/<ID>_thumbnail.png` (1280x720).
- Layout: top-left gold EP badge (episode order) + series name + scripture range; 2-3 lines of huge serif title (last line gold, usually the question); one dramatic image on the right; optional circled "proof" detail.
